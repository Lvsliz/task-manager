# Personal Task-Based Work Log V1.33

发布日期：2026-06-04

## 版本定位

V1.33 是面向团队看板能力继续演进的个人端版本。本版本重点补齐任务进度数据，让个人端可以更轻量地记录每个任务的当前完成度、步进和预计总耗时，并在同步看板时提供可检索的结构化字段。

## 主要更新

### 1. 任务进度快速操作

- 任务列表中的原“完成”操作调整为进度操作控件。
- 普通任务右侧显示 `- 进度% +`。
- 进度操作区遵循原交互原则：鼠标移动到任务上、任务被选中或键盘聚焦时才显示。
- 点击 `+` 会按任务配置的步进增加进度。
- 点击 `-` 会按任务配置的步进减少进度。
- 进度达到 `100%` 时，任务会自动标记为已完成。
- 进度从 `100%` 降回以下时，任务会恢复为进行中。
- 编辑按钮精简为铅笔图标，减少任务列表右侧操作区的文字占用。

### 2. 任务进度配置

任务编辑弹窗新增三个字段：

- 当前进度：0-100%，支持 1% 精度。
- 进度步进：默认 25%，支持任意 1% 步进。
- 预计总耗时：默认 3 天，最小 0.5 天，按 0.5 天递增。

历史已完成任务会自动规范为 `100%` 进度，剩余耗时为 `0`，避免出现“已完成但进度为 0%”的数据矛盾。

### 3. 看板同步字段增强

同步看板时，`worklog.json` 和 `worklog.md` 中每个任务新增以下字段：

```text
progress_percent
progress_step
estimated_days
remaining_days
```

这些字段用于后续团队看板直接统计每个人手上任务的剩余工作量，并支持按人员、任务和项目维度查询进度。

### 4. 日志加粗复制修复

- 修复从已有日志复制加粗内容到输入栏后，提交新日志时加粗格式丢失的问题。
- 现在提交时会识别 `<strong>`、`<b>` 以及显式 `font-weight` 加粗样式，并保存为 Markdown 加粗格式。
- 新日志保存后仍会正常渲染为加粗内容。

## 数据与隐私说明

本次发布包不包含任何本机已有数据。

发布包排除内容包括：

```text
worklog_v3.db
backup/
data/
server.out.log
server.err.log
build/
dist/
releases/
__pycache__/
```

便携版只包含空的 `data/` 目录。首次运行时会自动创建新的本地数据库和设置文件。
