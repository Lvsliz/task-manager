# Personal Task-Based Work Log V1.10

发布日期：2026-05-29

## 版本定位

V1.10 是基于 V1.0 试用基线的一次“高频记录体验 + UI 稳定性 + 日志置顶能力”版本。

本版本继续保持原有技术栈：

- Python + Flask
- SQLite
- 单页 HTML
- 原生 JavaScript
- 简单 CSS

这次没有引入复杂框架，也没有改变项目的基本结构。

## 主要更新

### 1. 日志输入增强

- 支持 `Ctrl+B` 对选中文本加粗。
- 输入框内可以直接看到加粗效果。
- 底层仍然保存为 Markdown 风格文本，例如 `**加粗内容**`。
- 继续支持 `Shift+Enter` 换行。
- 优化了输入框提示语颜色，使其弱于正式日志文本。

### 2. 日志置顶

- 新增单条日志置顶能力。
- 当前版本每个任务只允许置顶一条日志。
- 鼠标悬停日志时显示图钉按钮。
- 置顶日志显示在当前任务时间线顶部。
- 普通时间线中不重复显示已置顶日志。
- 置顶卡片隐藏时间，只突出日志内容。
- 优化了置顶卡片间距、对齐和右侧图钉显示。

### 3. 数据库升级到 schema v3

本版本将数据库 schema 从 v2 升级到 v3。

新增字段：

```text
logs.is_pinned INTEGER NOT NULL DEFAULT 0
logs.pinned_at TEXT
```

兼容方式：

- 旧日志不会丢失。
- 旧日志默认不置顶。
- 不修改历史日志内容。
- 不改变 Project / Task / Log 主链路。

开发过程中已在 migration 前备份数据库，备份文件位于：

```text
backup/
```

### 4. 中间日志栏布局优化

- 将“当前任务”区域整体上移，释放更多历史日志可见空间。
- 优化中间日志栏右侧边距，让文本区域更靠近滚动条。
- 增加稳定滚动条占位，避免有无滚动条时内容边界跳动。
- 保留之前的任务日志主显示逻辑。

### 5. 右侧任务列表布局优化

- 修复切换项目时，右上角“需关注”灯泡和“新建任务”按钮位置跳动的问题。
- 给右侧任务栏增加稳定滚动条占位。
- 收紧任务卡片和右侧滚动条之间的距离。
- 右上角操作区固定靠右，项目名称过长时不会挤动按钮。

### 6. 左侧导航优化

- 左侧“当前任务”入口改名为“进行中”，避免和中间“当前任务”标题混淆。
- 收紧左侧导航项之间的间距。
- 项目列表支持独立滚动。
- 设置按钮保持可见，不会被项目列表挤出窗口。
- 左上角按钮改为“任务分析”，暂时作为后续 AI 分析入口占位。
- 创建任务功能保留在右侧任务列表顶部。

### 7. 主题设置增强

- 主题数量从 9 种增加到 15 种。
- 新增主题：
  - 薄荷
  - 琥珀
  - 酒红
  - 海军
  - 青柠
  - 赤陶
- 修复“需关注”区域没有跟随主题色变化的问题。

### 8. 设置页面优化

- 设置页面支持内部滚动，适配较小窗口。
- 设置标题和“保存”按钮固定在顶部。
- 设置内容滚动时，顶部操作区不动。
- 将按钮文案从“完成”改为“保存”。
- 优化设置页滚动条位置，避免贴近圆角边缘。

### 9. 快速记录栏细节优化

- 时间选择框宽度会跟随当前选项变化。
- “现在”选项不再占用过宽空间。
- 日志输入区域获得更多横向空间。

## 源码包说明

源码包不包含本地运行数据。

排除内容包括：

- `worklog_v3.db`
- `backup/`
- `dist/`
- `releases/`
- `__pycache__/`
- server log files

## 便携版说明

便携版入口：

```text
dist/PersonalWorkLog/Worklog.exe
```

便携版运行数据目录：

```text
dist/PersonalWorkLog/data/worklog_v3.db
```

复制整个 `PersonalWorkLog` 文件夹到其他 Windows 电脑后，可以直接运行 `Worklog.exe` 试用。
