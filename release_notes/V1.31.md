# Personal Task-Based Work Log V1.31

发布日期：2026-06-03

## 版本定位

V1.31 是一次日志管理和分析历史导出的小版本更新。
本版本重点修正新建任务的默认项目来源，增加日志限时编辑能力，并补齐分析历史的 Markdown 导出流程。

## 主要更新

### 1. 新建任务默认项目优化

- 在左侧项目栏选中某个项目后，点击右上角“新建任务”时，会默认使用左侧当前选中的项目。
- 不再根据当前选中任务所属项目来决定新建任务的默认项目。
- 在非项目视图中创建任务时，仍会回退使用当前任务所属项目。

### 2. 日志 1 小时内可编辑

- 新增日志后，1 小时内可以编辑日志正文。
- 可编辑日志会在日志条目右侧显示铅笔按钮。
- 编辑日志使用应用内弹窗，不再使用浏览器原生输入窗口。
- 编辑框已适配当前主题样式，包括浅色边框、圆角和聚焦态。
- 后端会严格校验创建时间，超过 1 小时后禁止修改，避免绕过前端限制。

### 3. 分析历史 Markdown 导出

- 分析历史新增“导出”入口。
- 默认状态不显示勾选框，保持分析历史列表简洁。
- 点击“导出”后进入导出模式，才显示每条分析记录前的勾选框。
- 导出模式支持：
  - 导出选中
  - 导出全部
  - 取消导出
- 导出文件格式为 Markdown。
- 导出内容包含分析标题、类型、状态、任务、项目、创建时间、完成时间和分析结果。

### 4. 交互细节

- 导出成功后自动退出导出模式。
- 未选择任何分析记录时，“导出选中”保持禁用。
- 分析历史记录本身仍可点击查看分析结果。
- 保持现有任务导入导出、AI 分析、阶段总结和提示词设置逻辑不变。
