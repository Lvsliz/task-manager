# Personal Task-Based Work Log V1.0

Date: 2026-04-26

## Scope

V1.0 is the first stable trial baseline for the personal task-driven work log system.

## Highlights

- Rebuilt SQLite schema and initialization flow.
- Added explicit schema versioning.
- Stabilized bootstrap -> frontend state -> task rendering flow.
- Added default General project and Quick Record/Inbox baseline task.
- Preserved task, project, log, reminder, and timeline workflows.
- Redesigned the UI into sidebar, timeline, task list, and quick input regions.
- Added project navigation, needs-attention view, completed folding, and project rename.
- Added local folder path support for tasks.
- Added draggable timeline/task-list width adjustment.
- Added local theme settings with preset light themes.
- Added portable Windows folder build via PyInstaller.

## Portable Build

Portable build output:

```text
dist/PersonalWorkLog/Worklog.exe
```

Copy the whole `PersonalWorkLog` folder to another Windows computer to try it there.

## Data Notes

Runtime SQLite data is not part of the source baseline. The portable build stores runtime data in:

```text
dist/PersonalWorkLog/data/worklog_v3.db
```
